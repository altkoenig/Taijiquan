# Taijiquan

Unterprojekt rund um Taijiquan: Grundlagen, Vermarktung und weitere Themen.

## Bezeichnung

| Schreibweise | Form |
|---|---|
| Chinesisch (Kurzzeichen) | 太极拳 |
| Chinesisch (Langzeichen) | 太極拳 |
| Pinyin | Tàijíquán / Taijiquan |
| Wade-Giles | T'ai Chi Ch'üan |
| Deutsch (Duden) | das Tai-Chi |

- **太极 tàijí**: „das höchste Letzte“ (philosophisches Prinzip, Yin-Yang)
- **拳 quán**: „Faust“, „Boxen“, also Kampfkunst
- „Tai Chi“ ist Wade-Giles ohne Apostrophe. Das *chi* entspricht Pinyin *ji* (极). Es ist **nicht** *qi* (气, Lebensenergie).
- Für die Vermarktung: **Tai Chi** als bekannter Begriff, **Taijiquan (太极拳)** als fachlich korrekte Ergänzung.
